# MemBench

MemBench is being rebuilt as a scientifically defensible benchmark for
background-observer memory systems. This repository is private and currently
contains only a clean project shell and newly authored synthetic material.

No real corpus data, model transcripts, user content, historical repository
objects, evaluation artifacts, or memory-backend source code belong here.
Repository visibility must remain private unless the owner separately approves
a release after data authority, licensing, consent, independent review, and
release-attestation checks are complete.

The full methodology, synthetic quickstart, and OpenRouter-shaped reporting
contract will be added as the clean-room implementation is built and verified.

The release gate is a fail-closed publication safeguard over current files,
the Git index, and reachable history. Its bounded static checks are documented
in `SECURITY.md`; they are defense in depth and do not establish completeness
for runtime-generated keys, informal Markdown tables, or unsupported YAML and
TOML syntax.
